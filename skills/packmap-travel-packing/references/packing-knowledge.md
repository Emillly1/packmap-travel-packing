# Packing Knowledge Reference

Use this as a checklist prompt library. Select only relevant items; do not dump every category blindly.

## Recommendation Status

Assign one status when it helps the user decide:

- `bring`: essential, personalized, difficult to replace, or needed immediately.
- `buy_local`: bulky, inexpensive, easy to find, and not needed during transit or the first night.
- `optional`: comfort or activity item whose value depends on space and preference.
- `skip`: duplicate, incompatible, prohibited, or poor value for the itinerary.

For every non-obvious recommendation, connect it to a trip fact such as climate, activity, laundry interval, formal event, traveler count, or first-night need.

## Core Categories

Documents and money:
- Passport, visas/residence permits, school/work letters, insurance, emergency contacts, accommodation addresses, offline screenshots, copies, wallet/cards, local cash, student ID.

Electronics:
- Phone, laptop, tablet, chargers, cables, power bank, plug adapter, power strip, SIM/eSIM info, headphones, backup storage if needed.

Clothes:
- Tops, bottoms, underwear, socks, sleepwear, outer layer, rain layer, warm layer, formal/photo outfit, workout/loungewear, swimwear when relevant.

Shoes and bags:
- Daily comfortable shoes, outdoor shoes when relevant, shower slippers, small crossbody/waist bag, foldable tote, laundry bag, shoe bags.

Toiletries and skincare:
- Toothbrush/toothpaste, cleanser, makeup remover, moisturizer, body lotion, sunscreen, shampoo/conditioner, hair oil/mask, razor, soap/shower gel, towels, cotton swabs, menstrual products.

Medication and first aid:
- Personal prescriptions, painkiller, fever/cold basics, diarrhea medicine, rehydration plan or buy-local note, allergy medicine, motion sickness medicine, stomach medicine, disinfectant wipes, bandages/dressings.

Daily small items:
- Umbrella, tissues, wet wipes, mask, lip balm, hand cream, water bottle, utensils, reusable bag, notebook/pen.

## Trigger Rules

Study abroad or exchange:
- Add admission/school documents, student ID, laptop/tablet, stationery, calculator if course-related, formal opening event outfit, dorm essentials, laundry supplies, adaptors.

Long trip over one month:
- Pack by laundry cycle, not total days.
- Add backup glasses/contacts, extra medication, repair/safety items, small sewing or clips if user uses them, document copies.
- Split essentials across bags.

Multi-stage travel:
- Create stage bags: first city, travel interlude, long-stay base, cold-weather module, return/shopping overflow.
- Mark bags that should stay closed until later.
- Put the first-stage module in the easiest suitcase side to open.
- Keep one small transit module usable if checked luggage is delayed.

Two or more travelers:
- Create one document set per traveler and a shared backup copy.
- Split shared essentials instead of multiplying every item.
- Avoid putting every traveler's first-night clothes in one checked bag.

Flights and transfers:
- Add boarding passes, transfer details, baggage-through-check confirmation, airport-to-accommodation route, and offline addresses.
- Add a delay kit for long-haul or connecting flights.

Shopping or relocation:
- Reserve weight and volume, add a foldable bag only when airline allowance permits it, and identify consumables to buy locally.

Outdoor/hiking/Iceland/Nordic:
- Add rain shell, warm midlayer, thermal base layer, wool socks, sunscreen, sunglasses, lip balm, blister care, quick-dry clothes.

Hot summer city travel:
- Add sunscreen, hat/sunglasses, breathable tops, light cardigan, anti-chafe or blister care, insect repellent if mosquito-prone.

Formal/photo needs:
- Add one polished outfit, low-risk comfortable formal shoes or dressy flats, jewelry, wrinkle management, makeup/photo makeup, small bag.

Makeup/skincare/acne/dry skin:
- Add makeup remover, cleanser, moisturizer, body lotion, sunscreen, acne patches, gentle emergency basics, lip balm, hand cream.

Long hair/dry hair:
- Add hair ties, clip, brush/comb, conditioner/hair mask, hair oil, shower cap if used, heat tool only if voltage/plug compatible.

Menstrual needs:
- Add pads/tampons/cup, period underwear/sleep pants, painkiller, heat patch if used, spare underwear.

Glasses/contacts/OK lens:
- Add glasses, lens case, solution/cleaning tools, eye drops if used. Mark essential eye items as carry-on when vision depends on them.

Allergy-prone:
- Add personal allergy meds, topical allergy cream if used, note allergens, avoid introducing unfamiliar meds without pharmacist/doctor guidance.

Low blood sugar:
- Add fast sugar snacks or glucose tablets in personal item, not only checked bag.

## Transport Rules

Must carry-on:
- Passport, visas, boarding pass, wallet/cards/cash, keys, phone, power bank, lithium battery spares, laptop/tablet, jewelry, essential medicine, essential eyewear.

Must checked:
- Swiss army knife, knives, blades, large scissors, large liquid toiletries, full-size aerosols when permitted.

Risk reminders:
- Liquids can leak; double-bag and separate from electronics.
- Heavy items near suitcase wheels.
- Fragile items cushioned in clothes.
- Avoid putting all high-value or hard-to-replace items in checked luggage.
- Confirm airline-specific cabin dimensions, weight pooling, liquids, aerosols, and sports-equipment rules before departure.
