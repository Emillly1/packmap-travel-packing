# Privacy

PackMap `0.2.0-beta.1` is local-first.

- No account, cloud sync, advertising, or analytics service is included.
- Trip details, packing contents, and status are stored in the browser's local storage.
- Data leaves the browser only when the user explicitly downloads an export or feedback summary.
- Beta feedback summaries include version, current screen, aggregate container/item counts, browser identifier, and user-written feedback. They exclude item names, trip names, and destinations.
- “Clear all local data” removes the active project, rolling backup, import recovery point, and stored import source from this browser.

Browser profiles, device backups, downloaded exports, screenshots, and printed copies are outside PackMap's local-storage deletion boundary.
